WHAT THE AGENT WAS TOLD
Your task:

Create the package `app` (folder app/ with an empty __init__.py) and the module app/tracking.py. In app/tracking.py write a class `ParcelTracker` that keeps all data in memory. It takes no arguments when you create it. Each ParcelTracker object has its own separate data and its own number counter.

Method `register_parcel(shop: str, recipient: str) -> str`: registers a new parcel and returns its tracking number. A tracking number is the letters "PT" followed by exactly 8 digits. Numbers are given out in order, starting at 1, padded with zeros: the first parcel of a tracker gets "PT00000001", the second gets "PT00000002", and so on. Surrounding whitespace is removed from shop and recipient before they are stored. If shop or recipient is empty or only whitespace, raise ValueError and do not register anything (no number is used up).

Method `get_parcel(tracking_number: str) -> dict`: returns a new dict with exactly these keys: "tracking_number" (str), "shop" (str), "recipient" (str), "status" (str). A newly registered parcel has status "registered". If the tracking number is unknown, raise KeyError. The returned dict is a copy: changing it must not change the data stored in the tracker.
